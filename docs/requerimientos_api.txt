**Fase 3: Depuración y Pruebas de Integración** `[EN PROGRESO]`

**Descripción:**
Una vez completado el desarrollo inicial de las Fases 1 y 2, se inicia el proceso de pruebas integrales para validar la comunicación
 entre el frontend (Android) y el backend (Spring Boot). Durante esta fase se han identificado y solucionado varios problemas.

**Historial de Problemas y Soluciones:**

1.  **Error de Red: `CLEARTEXT communication not permitted`** `[SOLUCIONADO]`
    *   **Análisis:** Android (API 28+) prohíbe por defecto las conexiones `http` (no seguras). La `BASE_URL` del cliente Retrofit
 usa `http://10.0.2.2:8080/`.
    *   **Solución Aplicada:** Se añadió `android:usesCleartextTraffic="true"` al `<application>` en `AndroidManifest.xml` para permitir la comunicación en el entorno de desarrollo local.

2.  **Error de Autenticación:
 `HTTP 401 Unauthorized`** `[SOLUCIONADO]`
    *   **Análisis:** Spring Security estaba protegiendo todos los endpoints por defecto. La petición de registro a `POST /api/usuariosK/register` no estaba en la lista de rutas públicas permitidas.
    *   **Solución
 Aplicada:** Se modificó la clase `SecurityConfig.java` en el backend para añadir `requestMatchers(HttpMethod.POST, "/api/usuariosK/register").permitAll()`, permitiendo el acceso anónimo a dicho endpoint.

**Problema Actual: Error Interno del Servidor `HTTP 500`** `[PENDIENTE]`

*   **Estado:** Al intentar registrar un usuario (en el "happy path"), la app recibe un código de estado `HTTP 500`.
*   **Análisis:**
    Un error 500 indica que la petición ha superado las barreras de red y seguridad, llegando exitosamente al `Controller` y al
 `Service` del backend. Sin embargo, una excepción no controlada ha ocurrido *dentro* de la lógica del servidor mientras procesaba la petición.

**Plan de Acción para Resolver el Error 500:**

1.  **Replicar el Error y Capturar el Stack Trace:**
    *   `[ACCIÓN]` Reiniciar el servidor de backend (Spring Boot).
    *   `[ACCIÓN]` Realizar
 una petición de registro desde la app Android para provocar el error 500.
    *   `[ACCIÓN]` Inmediatamente después del error, ir a la consola del IDE donde corre el backend y **copiar el log de error completo (el "stack trace" rojo)**.

2.  **Analizar el Stack Trace para Identificar la Causa Raíz:**
    La causa más probable es una de las siguientes:
    *   **Sospechoso #1: Error de Conexión con la Base de Datos:** Una mala configuración en `application.properties` (URL, usuario,
 contraseña) o la falta del driver de la BD puede causar que las operaciones del `Repository` fallen.
    *   **Sospechoso #2: `NullPointerException`:** Un objeto no se ha inyectado o inicializado correctamente antes de ser usado. Un candidato común es el
     `passwordEncoder` en `UsuarioService`.
        *   **Sospechoso #3: Conflicto entre Entidad JPA y Tabla de la BD:** Una discrepancia en los nombres de columna, tipos de datos o restricciones (`NOT NULL`) entre la clase `@Entity Usuario` y la tabla `usuario`
         en la base de datos.

        3.  **Aplicar la Solución:**
            *   `[ACCIÓN]` Una vez identificada la línea y la causa del error en el stack trace, aplicar la corrección correspondiente en el código del backend.
            *   `[ACCIÓN]` Reiniciar el servidor y volver a probar el "happy path" desde la app.

package com.example.SaveUp.model;

import lombok.AllArgsConstructor;

import jakarta.validation.constraints.*;

@Entity
@Table(name = "USUARIO")
@Data
@AllArgsConstructor
@NoArgsConstructor
public class Usuario {

    // RUT como ID, formato chileno con guion y verificador numérico o letra k/K
    @Id
    @Column(name = "ID_USUARIO", unique = true)
    @NotBlank(message = "El RUT es obligatorio")
    @Pattern(regexp = "^\\d{7,8}-[\\dkK]{1}$", message = "El RUT debe tener el formato 12345678-9 o 12345678-k")
    private String rut;

    @Column(name = "NOMBRE", nullable = false, length = 100)
    @NotBlank(message = "El nombre es obligatorio")
    @Size(min = 3, max = 20, message = "El nombre debe tener entre 3 y 20 caracteres")
    private String nombre;

    @Column(name = "APELLIDO", nullable = false, length = 100)
    @NotBlank(message = "El apellido es obligatorio")
    @Size(min = 3, max = 20, message = "El apellido debe tener entre 3 y 20 caracteres")
    private String apellido;

    @Column(name = "EMAIL", nullable = false, unique = true, length = 150)
    @NotBlank(message = "El correo es obligatorio")
    @Email(message = "Formato de correo inválido")
    private String email;

    @Column(name = "CONTRASENA_HASH", nullable = false, length = 100)
    @NotBlank(message = "La contraseña es obligatoria")
    @Size(min = 7, max = 20, message = "La contraseña debe tener entre 7 y 20 caracteres")
    @Pattern(regexp = "^(?=.*[A-Za-z])(?=.*\\d)[A-Za-z\\d]{7,20}$", message = "La contraseña debe contener al menos una letra y un número")
    private String contrasena;


    @Column(name = "FECHA_REGISTRO", nullable = false, updatable = false)
    @Temporal(TemporalType.TIMESTAMP)
    private Date fechaRegistro;

    @PrePersist
    protected void onCreate() {
        this.fechaRegistro = new Date();
    }

    @OneToMany(mappedBy = "usuario")

    public boolean usuarioExcedePresupuesto(String rut, String categoriaStr) {
        Usuario usuario = findByRut(rut);
        if (usuario == null) {
            throw new EntityNotFoundException("Usuario no encontrado.");
        }

        CategoriaPresupuesto categoria;
        try {
            categoria = CategoriaPresupuesto.valueOf(categoriaStr.toUpperCase());
        } catch (IllegalArgumentException e) {
            throw new IllegalArgumentException("Categoría inválida: " + categoriaStr);
        }

        List<Presupuesto> presupuestos = presupuestoRepository.findByUsuario_RutAndCategoria(rut, categoria);

        for (Presupuesto presupuesto : presupuestos) {
            List<Gasto> gastos = gastoRepository.findByUsuario_RutAndCategoria(rut, categoria).stream()
                .filter(g -> {
                    Date fecha = g.getFechaGasto();
                    return fecha != null &&
                        !fecha.before(presupuesto.getFechaInicio()) &&
                        !fecha.after(presupuesto.getFechaTermino());
                })
                .collect(Collectors.toList());

            if (presupuesto.estaExcedido(gastos)) {
                return true;
            }
        }

        return false;
    }

    public float presupuestoRestante(String rut, String categoriaStr) {
        Usuario usuario = findByRut(rut);
        if (usuario == null) {
            throw new EntityNotFoundException("Usuario no encontrado.");
        }

        CategoriaPresupuesto categoria;
        try {
            categoria = CategoriaPresupuesto.valueOf(categoriaStr.toUpperCase());
        } catch (IllegalArgumentException e) {
            throw new IllegalArgumentException("Categoría inválida: " + categoriaStr);
        }

        List<Presupuesto> presupuestos = presupuestoRepository.findByUsuario_RutAndCategoria(rut, categoria);

        if (presupuestos.isEmpty()) return -1;

        Presupuesto actual = presupuestos.get(0); // Suponiendo uno activo

        List<Gasto> gastos = gastoRepository.findByUsuario_RutAndCategoria(rut, categoria).stream()
            .filter(g -> {
                Date fecha = g.getFechaGasto();
                return fecha != null &&
                    !fecha.before(actual.getFechaInicio()) &&
                    !fecha.after(actual.getFechaTermino());
            })
            .collect(Collectors.toList());

        return actual.calcularRestante(gastos);
    }



    public Usuario registrarUsuario(RegistroRequest request) {
        // Validar si ya existe el usuario por RUT o correo
        if (usuarioRepository.existsById(request.getRut())) {
            throw new IllegalArgumentException("Ya existe un usuario con el RUT proporcionado.");
        }

        if (usuarioRepository.findByEmail(request.getEmail()).isPresent()) {
            throw new IllegalArgumentException("Ya existe un usuario con el correo proporcionado.");
        }

        // Validar contraseña
        String contrasena = request.getContrasena();
        if (!contrasena.matches("^[a-zA-Z0-9]{7,}$") || !contrasena.matches(".*\\d.*")) {
            throw new IllegalArgumentException("La contraseña debe tener al menos 7 caracteres, incluir al menos un número y no contener caracteres especiales.");
        }

        // Crear y poblar el nuevo Usuario
        Usuario nuevoUsuario = new Usuario();
        nuevoUsuario.setRut(request.getRut());
        nuevoUsuario.setNombre(request.getNombre());
        nuevoUsuario.setApellido(request.getApellido());
        nuevoUsuario.setEmail(request.getEmail());
        nuevoUsuario.setContrasena(passwordEncoder.encode(contrasena));
        nuevoUsuario.setFechaRegistro(new Date()); // Garantiza que se guarde la fecha actual

        return usuarioRepository.save(nuevoUsuario);
    }

    /**
     * Registra un nuevo usuario proveniente desde la aplicación Android.
     * Recibe un DTO, lo convierte en una entidad Usuario, valida la existencia,
     * hashea la contraseña y lo persiste en la base de datos.
     *
     * @param usuarioDTO El objeto DTO con los datos del nuevo usuario.
     * @return La entidad Usuario guardada.
     * @throws IllegalArgumentException si el RUT o el email ya existen.
     */
    public Usuario registrarUsuarioDesdeApp(UsuarioKotlinDTO usuarioDTO) {
        // 1. Validar si ya existe el usuario por RUT o correo
        if (usuarioRepository.existsById(usuarioDTO.getRut())) {
            throw new IllegalArgumentException("El RUT ya está registrado.");
        }
        if (usuarioRepository.findByEmail(usuarioDTO.getEmail()).isPresent()) {
            throw new IllegalArgumentException("El correo electrónico ya está registrado.");
        }

        // 2. Crear una nueva instancia de la entidad Usuario
        Usuario nuevoUsuario = new Usuario();

        // 3. Mapear los datos del DTO a la entidad
        nuevoUsuario.setRut(usuarioDTO.getRut());
        nuevoUsuario.setNombre(usuarioDTO.getNombre());
        nuevoUsuario.setApellido(usuarioDTO.getApellido());
        nuevoUsuario.setEmail(usuarioDTO.getEmail());
        
        // 4. Hashear la contraseña antes de guardarla (¡Paso de seguridad crítico!)
        nuevoUsuario.setContrasena(passwordEncoder.encode(usuarioDTO.getContrasena()));
        
        // 5. Establecer la fecha de registro
        nuevoUsuario.setFechaRegistro(new Date());

        // 6. Guardar la nueva entidad en la base de datos y retornarla
        return usuarioRepository.save(nuevoUsuario);
    }

        float monto = (ultimoSaldo != null) 
            ? ultimoSaldo.getMonto() 
            : 0f;

        return ResponseEntity.ok(monto);
    }

    // ✅ Iniciar sesión
    @PostMapping("/login")
    public ResponseEntity<String> iniciarSesion(
            @RequestParam String email,
            @RequestParam String contrasena) {
        boolean autenticado = usuarioService.iniciarSesion(email, contrasena);
        return autenticado
            ? ResponseEntity.ok("Inicio de sesión exitoso.")
            : ResponseEntity.status(HttpStatus.UNAUTHORIZED).body("Credenciales inválidas.");
    }

    // ✅ Cerrar sesión
    @PostMapping("/logout/{rut}")
    public ResponseEntity<String> cerrarSesion(@PathVariable String rut) {
        usuarioService.cerrarSesion(rut);
        return ResponseEntity.ok("Sesión cerrada.");
    }

    // ✅ Actualizar nombre y correo
    @PutMapping("/{rut}/actualizar-datos")
    public ResponseEntity<String> actualizarDatos(
            @PathVariable String rut,
            @RequestParam String nombre,
            @RequestParam("correo") String correo) {
        usuarioService.actualizarDatos(rut, nombre, correo);
        return ResponseEntity.ok("Datos actualizados.");
    }

    // ✅ Recuperar contraseña
    @PostMapping("/recuperar-contrasena/{rut}")
    public ResponseEntity<String> recuperarContrasena(@PathVariable String rut) {
        usuarioService.recuperarContrasena(rut);
        return ResponseEntity.ok("Instrucciones de recuperación enviadas.");
    }

    // ✅ Obtener perfil del usuario autenticado
    @GetMapping("/perfil")
    public Usuario obtenerPerfil(@AuthenticationPrincipal UserDetailsImpl userDetails) {
        return userDetails.getUsuario();
    }

package com.example.SaveUp.controller;

import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PathVariable;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;

import com.example.SaveUp.DTO.UsuarioKotlinDTO;
import com.example.SaveUp.model.Usuario;
import com.example.SaveUp.service.UsuarioService;

import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.http.HttpStatus;
import org.springframework.http.ResponseEntity;

@RestController
@RequestMapping("/api/usuariosK")
public class UsuarioKotlinController {

    @Autowired
    private UsuarioService usuarioService;

    @GetMapping("/{rut}")
    public ResponseEntity<UsuarioKotlinDTO> getUsuarioByRut(@PathVariable String rut) {
        Usuario usuarioEntity = usuarioService.findByRut(rut);

        if (usuarioEntity == null) {
            return ResponseEntity.notFound().build();
        }

        UsuarioKotlinDTO usuarioDTO = convertToDto(usuarioEntity);
        return ResponseEntity.ok(usuarioDTO);
    }

    private UsuarioKotlinDTO convertToDto(Usuario entity) {
        return new UsuarioKotlinDTO(
            entity.getRut(),
            entity.getNombre(),
            entity.getApellido(),
            entity.getEmail(),
            null,  // Se omite la contraseña en la respuesta
            entity.getFechaRegistro()
        );
    }

    /**
     * Endpoint para registrar un nuevo usuario desde la aplicación Android.
     *
     * @param usuarioDTO Los datos del usuario a registrar, recibidos en el cuerpo de la petición.
     * @return Una respuesta HTTP 201 (Created) si el registro es exitoso,
     *         o una respuesta HTTP 409 (Conflict) si el usuario ya existe.
     */
    @PostMapping("/register")
    public ResponseEntity<Void> registerUsuario(@RequestBody UsuarioKotlinDTO usuarioDTO) {
        try {
            usuarioService.registrarUsuarioDesdeApp(usuarioDTO);
            // Si el registro es exitoso, devuelve el código de estado 201 Created.
            return new ResponseEntity<>(HttpStatus.CREATED);
        } catch (IllegalArgumentException e) {
            // Si el servicio lanza una excepción (porque el usuario ya existe),
            // devuelve el código de estado 409 Conflict.
            // Podríamos también devolver el mensaje de error en el cuerpo si quisiéramos.
            return new ResponseEntity<>(HttpStatus.CONFLICT);
        }
    }
}

package com.example.SaveUp.security;

import jakarta.servlet.http.HttpServletResponse;
import lombok.RequiredArgsConstructor;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.http.HttpMethod;
import org.springframework.security.authentication.AuthenticationManager;
import org.springframework.security.authentication.dao.DaoAuthenticationProvider;
import org.springframework.security.config.Customizer;
import org.springframework.security.config.annotation.web.configuration.EnableWebSecurity;
import org.springframework.security.config.annotation.authentication.configuration.AuthenticationConfiguration;
import org.springframework.security.config.annotation.web.builders.HttpSecurity;
import org.springframework.security.config.http.SessionCreationPolicy;
import org.springframework.security.config.annotation.web.configurers.AbstractHttpConfigurer;
import org.springframework.security.core.userdetails.UserDetailsService;
import org.springframework.security.crypto.bcrypt.BCryptPasswordEncoder;
import org.springframework.security.crypto.password.PasswordEncoder;
import org.springframework.security.web.SecurityFilterChain;
import org.springframework.security.web.authentication.UsernamePasswordAuthenticationFilter;

@RequiredArgsConstructor
@Configuration
@EnableWebSecurity
public class SecurityConfig {

    private final JwtAuthenticationFilter jwtAuthFilter;
    private final UserDetailsService userDetailsService;

    @Bean
    public SecurityFilterChain securityFilterChain(HttpSecurity http) throws Exception {
        http
            // 1) CSRF deshabilitado
            .csrf(AbstractHttpConfigurer::disable)
            // 2) CORS según tu WebConfig
            .cors(Customizer.withDefaults())
            // 3) Sesión stateless
            .sessionManagement(sm -> sm
                .sessionCreationPolicy(SessionCreationPolicy.STATELESS)
            )
            // 4) Manejo de errores: 401 si no está autenticado
            .exceptionHandling(ex -> ex
                .authenticationEntryPoint((req, res, authEx) ->
                    res.sendError(HttpServletResponse.SC_UNAUTHORIZED, authEx.getMessage())
                )
            )
            // 5) Autorización de rutas
            .authorizeHttpRequests(auth -> auth
                // Preflight CORS
                .requestMatchers(HttpMethod.OPTIONS, "/**").permitAll()

                // ================== INICIO DEL CAMBIO ==================
                // Permitir el endpoint de registro de la app Kotlin
                .requestMatchers(HttpMethod.POST, "/api/usuariosK/register").permitAll()
                // =================== FIN DEL CAMBIO ====================

                // Mantener tus rutas existentes para la web u otras partes
                .requestMatchers(HttpMethod.POST, "/api/auth/register", "/api/auth/login").permitAll()
                .requestMatchers(HttpMethod.POST, "/api/auth/recuperar/validar",
                                         "/api/auth/recuperar/actualizar")
                  .permitAll()
                // Recuperar contraseña
                .requestMatchers(HttpMethod.GET, "/api/usuarios/recuperar-contrasena/**").permitAll()

                // Resto protegido
                .anyRequest().authenticated()
            )
            // 6) Proveedor de autenticación y filtro JWT
            .authenticationProvider(authenticationProvider())
            .addFilterBefore(jwtAuthFilter, UsernamePasswordAuthenticationFilter.class);

        return http.build();
    }

    @Bean
    public DaoAuthenticationProvider authenticationProvider() {
        DaoAuthenticationProvider provider = new DaoAuthenticationProvider();
        provider.setUserDetailsService(userDetailsService);
        provider.setPasswordEncoder(passwordEncoder());
        return provider;
    }

    @Bean
    public AuthenticationManager authenticationManager(
            AuthenticationConfiguration config
    ) throws Exception {
        return config.getAuthenticationManager();
    }

    @Bean
    public PasswordEncoder passwordEncoder() {
        return new BCryptPasswordEncoder();
    }
}
