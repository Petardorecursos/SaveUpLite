# Documentación de Diseño: Rework Visual de SaveUp Lite

Este documento detalla el rediseño visual y las implementaciones de funcionalidades en la aplicación.

## 1. Filosofía de Diseño

El estilo visual se divide en dos enfoques principales:
- **Diseño Limpio y Moderno (Autenticación):** Utiliza una estructura de dos tonos con un encabezado de color y una tarjeta de formulario limpia.
- **Soft UI (Dashboard y Pantallas Interiores):** Utiliza tarjetas de colores suaves, elevaciones sutiles y una barra de navegación inferior flotante con efecto "extruido".

Se mantiene la consistencia en la paleta de colores, tipografía e iconografía.

---

## 2. Paleta de Colores y Tipografía

- **Colores:** Definidos en `Color.kt`. La paleta incluye un fondo `SoftWhite`, un acento primario `LavenderBlue` y acentos secundarios como `PaleAqua` y `PalePink`.
- **Tipografía:** Estandarizada con la fuente **Inter**, configurada en `Type.kt`. (Requiere añadir los archivos de fuente a `res/font`).

---

## 3. Estructura de Navegación y Pantallas

- **Barra de Navegación Inferior:** Implementada en `DashboardScreen.kt`, contiene las secciones: **Inicio**, **Deudas**, **Metas** y **Mercado**. Utiliza un estilo "Soft UI" con efecto de extrusión.
- **`AuthScreen.kt`:** Pantalla de autenticación con diseño de dos tonos.
- **`DashboardScreen.kt`:** Pantalla principal que aloja la navegación y las funciones primordiales de "Ingreso" y "Gasto".
- **`NavGraph.kt`:** Contiene todas las rutas de navegación, incluyendo marcadores de posición para las pantallas futuras.

---

## 6. Integración de APIs Externas

### 6.1. API de Indicadores Económicos (mindicador.cl)

Se ha implementado una nueva funcionalidad para consumir y mostrar indicadores económicos relevantes para el mercado chileno.

**Arquitectura Implementada:**

- **Capa de Datos (`/api` y `/model/dto`):**
    - **`IndicadorEconomicoDTO.kt`:** Modelo para un indicador individual (dólar, UF, etc.).
    - **`IndicadoresResponseDTO.kt`:** Modelo para la respuesta JSON completa de la API.
    - **`MindicadorApiService.kt`:** Nueva interfaz de Retrofit exclusiva para esta API, con el método `getIndicadoresEconomicos()`.
    - **`MindicadorRetrofitClient.kt`:** Nuevo cliente de Retrofit configurado con la URL base `https://mindicador.cl/` y un `GsonConverterFactory` para parsear las fechas.

- **Capa de Lógica (`/viewmodel`):**
    - **`MarketViewModel.kt`:** Nuevo ViewModel que se encarga de:
        - Llamar al `MindicadorApiService`.
        - Gestionar el estado de la UI (`MarketUiState`) con los estados de carga, éxito (lista de indicadores) y error.
        - Exponer los datos a la UI a través de un `StateFlow`.

- **Capa de Presentación (`/ui/screens`):**
    - **`MarketScreen.kt`:** Nueva pantalla que:
        - Observa el estado del `MarketViewModel`.
        - Muestra un `CircularProgressIndicator` durante la carga.
        - Presenta la lista de indicadores en una `LazyColumn` usando un componente `IndicadorCard` estilizado.
        - Muestra mensajes de error si la carga falla.
    - **Actualización en `NavGraph.kt`:** Se ha reemplazado el `PlaceholderScreen` de la ruta `MARKET` por el nuevo `MarketScreen`.
