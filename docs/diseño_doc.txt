# Documentación de Diseño: Rework Visual de SaveUp Lite

Este documento detalla el rediseño visual de la aplicación implementado para adoptar un estilo moderno, limpio y cohesivo.

## 1. Filosofía de Diseño

El estilo visual se divide en dos enfoques principales para crear una experiencia de usuario rica y contextual:

- **Diseño Limpio y Moderno (Pantalla de Autenticación):** Inspirado en diseños contemporáneos, esta pantalla utiliza una estructura de dos tonos con un encabezado de color y una tarjeta de formulario limpia que se desliza desde abajo. El objetivo es ser amigable, directo y visualmente atractivo para el primer contacto del usuario.

- **Soft UI (Dashboard y Pantallas Interiores):** Una vez dentro de la aplicación, la interfaz cambia a un estilo "Soft UI" o "Neumorfismo-lite". Se utilizan tarjetas de colores suaves con elevaciones y esquinas redondeadas para presentar datos de forma clara y tranquila.

- **Consistencia:** A pesar de los dos enfoques, se mantiene la misma paleta de colores, tipografía e iconografía en toda la aplicación para garantizar una experiencia unificada.

---

## 2. Paleta de Colores

Se implementó una paleta de colores natural y cálida, definida en `app/src/main/java/com/example/saveuplite/ui/theme/Color.kt`.

- **Fondo Principal:** `SoftWhite` (#F8F8FA) y `Color.White` para las tarjetas de formulario.
- **Acento Primario:** `LavenderBlue` (#7E8CE7) - Usado para botones principales y elementos interactivos.
- **Acentos Secundarios:**
    - `PaleAqua` (#E0F5F2): Usado para el encabezado en la pantalla de autenticación y botones de "ingreso".
    - `PalePink` (#F8E7EA): Para acciones de "gasto".
    - `MediumBlue` (#E1E4F9): Para tarjetas de datos importantes como el saldo.
- **Colores de Texto:**
    - `DarkGrayText` (#333333): Para títulos y texto principal.
    - `MediumGrayText` (#888888) / `LightGrayText` (#A0A0A0): Para subtítulos y placeholders.

---

## 3. Tipografía

Se ha estandarizado el uso de la familia de fuentes **Inter**. La configuración se encuentra en `app/src/main/java/com/example/saveuplite/ui/theme/Type.kt`.

**ACCIÓN REQUERIDA:** Añadir los archivos de fuente `.ttf` de "Inter" al directorio `app/src/main/res/font`.

---

## 4. Iconografía

Se ha estandarizado el uso de íconos de la variante **Outlined** de Material Design para mantener una apariencia visual ligera.

---

## 5. Pantallas y Componentes Modificados

- **`AuthScreen.kt` (Diseño Limpio y Moderno):**
    - **Estructura:** Pantalla dividida en dos. Un encabezado superior (30% de la pantalla) con fondo `PaleAqua` y una tarjeta de formulario blanca con esquinas superiores redondeadas que ocupa el resto del espacio.
    - **Encabezado:** Contiene el saludo y el logo "SaveUp" con una nueva jerarquía visual. Utiliza la imagen `auth_background.jpg` como un patrón sutil y semitransparente.
    - **Campos de Texto:** Se utiliza un `AuthTextField` personalizado, que es un `OutlinedTextField` estilizado con fondo `SoftWhite` y sin borde en estado de reposo, para un look minimalista.
    - **Botones Sociales:** Se añadió la estructura visual para botones de inicio de sesión con Google, Facebook y Apple (actualmente comentada en el código para evitar errores de compilación).

- **`DashboardScreen.kt` (Estilo Soft UI):**
    - `TopAppBar` transparente.
    - `BalanceCard` usa el color `MediumBlue`.
    - `ActionButtons` usan los colores `PaleAqua` y `PalePink`.
    - `TransactionItem` son tarjetas limpias y redondeadas.

- **`TransactionHistoryScreen.kt` (Estilo Soft UI):**
    - Mantiene la consistencia con el Dashboard, usando fondo `SoftWhite` y `TopAppBar` transparente.
    - Reutiliza el `TransactionItem` para coherencia visual.
